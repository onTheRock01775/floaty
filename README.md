# Floaty

Windows app for arranging game windows, picture-in-picture views, and Skill panels.

## Downloads

Download `Floaty-windows.zip` from [Releases](https://github.com/onTheRock01775/floaty/releases) when a release is available.
Extract the ZIP and keep `Floaty.exe` and `FloatyUpdater.exe` in the same folder.
Discord sign-in requires the Supabase configuration supplied by your administrator.

## Updates

Floaty checks this repository for stable releases at sign-in and periodically while running.
Use the update button to read release notes, download a patch, and install when ready.
The app restores managed game windows before closing for installation and backs up replaced files.

This repository is used for release distribution. Local configuration files and credentials should not be uploaded here.
